# 🚀 Data Warehouse and Analytics Project

Welcome to my **Data Warehouse and Analytics Project**!

This project demonstrates an end-to-end data warehousing and analytics solution built using **Microsoft SQL Server**. It covers the process of building a data warehouse, integrating data from multiple source systems, performing data cleansing, and generating meaningful business insights through SQL analytics.

The project is part of my journey toward becoming a **Data Engineer** and showcases practical skills, industry best practices, and real-world data engineering concepts.

---

## 📌 Project Overview

This project is divided into two main parts:

### 1. Data Warehouse Development (Data Engineering)

**Objective:**

Build a modern data warehouse using SQL Server to consolidate sales data from multiple source systems and create a reliable foundation for analytical reporting.

**Requirements:**

- **Data Sources:** Import data from two source systems (ERP and CRM), provided as CSV files.
- **Data Quality:** Clean and resolve data quality issues before loading the data into the warehouse.
- **Data Integration:** Combine data from both sources into a unified, user-friendly data model.
- **Scope:** Focus on the latest available dataset. Historical data tracking is not required.
- **Documentation:** Provide clear documentation of the data model to support business stakeholders and analytics teams.

### 2. BI: Analytics & Reporting (Data Analytics)

**Objective:**

Develop SQL-based analytical queries to generate insights into key business areas:

- **Customer Behavior:** Understand customer patterns and purchasing behavior.
- **Product Performance:** Analyze product performance and identify popular products.
- **Sales Trends:** Explore sales patterns and track business performance.

These insights help stakeholders understand business performance and make data-driven decisions.
